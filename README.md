# UniSquad Pro — منصة الشلة الجامعية

منصة ويب مغلقة للطلاب الجامعيين للمذاكرة، مشاركة الروابط والمحاضرات، تتبع الحضور، وجدولة جلسات المذاكرة أونلاين.

## الميزات

- **تسجيل دخول وتسجيل حساب** مع أكواد اشتراك
- **المنشورات والأسئلة** مع التعليقات
- **مكتبة الروابط** (Drive، محاضرات، شيتات)
- **تتبع الحضور** (نازل / احتمال / غايب)
- **جلسات المذاكرة** (Zoom / Google Meet)
- **لوحة إشراف** للأدمن (توليد أكواد، حظر مؤقت، تغيير كلمة السر)
- دعم الوضع الداكن (Dark Mode)

## تشغيل المنصة

افتح ملف `index.html` مباشرة في المتصفح، أو ارفعه على أي استضافة ثابتة (GitHub Pages، Netlify، Vercel...).

### حساب الأدمن التجريبي
- اسم المستخدم: `admin`
- كلمة السر: `admin123`

## التقنيات

- HTML + Tailwind CSS + Font Awesome
- Vanilla JavaScript
- localStorage / sessionStorage (بدون باكند حالياً)

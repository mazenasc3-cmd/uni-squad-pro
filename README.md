# UniSquad Pro — منصة الشلة الجامعية

منصة ويب مغلقة للطلاب الجامعيين للمذاكرة، مشاركة الروابط والمحاضرات، تتبع الحضور، وجدولة جلسات المذاكرة أونلاين.

## الميزات

- **تسجيل دخول وتسجيل حساب** مع أكواد اشتراك
- **المنشورات والأسئلة** مع التعليقات + دعم صور وريكوردات صوتية
- **مكتبة الروابط** (Drive، محاضرات، شيتات)
- **تتبع الحضور** (نازل / احتمال / غايب)
- **جلسات المذاكرة** (Zoom / Google Meet)
- **لوحة إشراف** للأدمن (توليد أكواد، حظر مؤقت، تغيير كلمة السر، تخصيص أسماء النوافذ)
- الوضع الداكن / الفاتح

## طريقتان للتشغيل

### 1. الوضع البسيط (Static / بدون سيرفر)
افتح ملف `index.html` مباشرة في المتصفح، أو ارفعه على أي استضافة ثابتة (GitHub Pages، Netlify، Cloudflare Pages...).

البيانات هتتسجل محلياً في المتصفح (`localStorage`).

### 2. الوضع الكامل (مع قاعدة بيانات Neon + Vercel)
1. أنشئ مشروع على [Neon](https://neon.tech) وخذ `DATABASE_URL`.
2. ارفع المشروع على Vercel.
3. أضف Environment Variable: `DATABASE_URL` = رابط Neon.
4. المنصة هتستخدم قاعدة البيانات الحقيقية وهتبقى مشتركة بين كل الأجهزة.

ملف `vercel.json` جاهز للتعامل مع الـ serverless function.

### حساب الأدمن الافتراضي
- اسم المستخدم: `admin`
- كلمة السر: `admin123`

**مهم:** غيّر كلمة سر الأدمن من لوحة الإشراف فور أول دخول.

## التقنيات

- HTML + Tailwind CSS + Font Awesome + Cairo Font
- Vanilla JavaScript
- Backend اختياري: Node.js Serverless + Neon PostgreSQL (`@neondatabase/serverless`)
